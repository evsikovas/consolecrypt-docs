# ConsoleCrypt 1.0.6

参考文档译文 · [俄文原文](../RELEASE_1_0_6.md)

## 俄罗斯语

密码管理者篮子KDBX现在有一个购物车图标和可以理解的行动.

- 当选择其中的篮子或文件夹时,按钮** 清除篮子** 可用.
  这一动作也在推车本身的**.**/PCM菜单中。
- 在确认后,所有组、巢组和
  入项** 篮子。 篮子外的现有数据被存储.
- 对于单独的远程组或菜单项,**永远删除**。
  亦已证得. 删除一个组包括它的嵌入式文件夹和记录.
- 篮子的系统文件夹仍为空 。 一个叫“ 回收站” 的普通文件夹
  定义为普通文件夹:动作与篮子IDKDBX链接.
- 更改立即在当地或通过WebDAV存储. 在所选范围内搜索
  回收桶会找到被删除的条目;一般搜索和调色板会继续将其排除在外.

固定装置有Windows,macOS,LinuxDEB/RPM,Android和iOS模拟器.
同步协议和服务器不改变 。

另外,装有大量CI组装装置的安装机组装Windows也得到了纠正.
应用程序的完整版本和检查更新被保存.
