## 发布文件

- Windows x64:EXE安装器和便携式ZIP.
- macOS 苹果硅/英特尔:通用DMG.
- Linux×64:DEB和RPM;与特勤局的桌面环境.
- AndroidARM64:由APK签署,Android11+.
- iOS:Mac上的模拟器通用ZIP应用,iOS15+.
  它不是IPA、TestFlight或物理的iPhone应用。

每个软件包的构建版本/编号和SHA-256都发布. iOS模拟器.
问题1.0.0的强制性CI中包括:没有它的档案会阻碍出版物的出版。

## 密码的存储和同步

选中的本地文件会在计算机上编辑 。 电话系统。
采摘者可以退回临时副本,所以ConsoleCrypt进口.
在其永久私人存储中加密KDBX. 自动保存更改
此副本;"保存本地副本"通过系统对话框上传.
电话的原始文件不是自发的覆写.

WebDAV所有平台的作品相同: HTTPS URL带有一个最终的`.kdbx`.
防范冲突版本,自动节约,取消开放和超时.
参数WebDAV在内部同步E2EE,密码是单独的密语.
本地路径、生物鉴别信封和储存Docker/Kubernetes - 通道
