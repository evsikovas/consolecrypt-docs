## 什么变了?

共享选中的主机、 片段、 收藏和单独共享
已经确认的秘密。 个人 VRK没有传输 。 设备正在验证全部
代码;每个对象使用自己的DEK和参与者信封.
读取器/编辑器,有旋转的反馈,有加密更改的队列,
检查已签名的历史, 并在操作中断后恢复 。
允许通过所有者在线获取其他专有设备
具有角色上限、任期和配额的许可证;使用人工模式
[Процесс и границы защиты](SHARING.md)

固定最后交付SSH和闲置关闭
FRB流:原产地制作人关闭,然后是旧订阅.
旧连接的后期事件不能完成新连接 。

添加iOS 跑者、静态碎屑核、键链/地方认证,
流动警卫和独立回归/审查任务。
