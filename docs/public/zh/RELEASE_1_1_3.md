# ConsoleCrypt 1.1.3

参考文档译文 · [俄文原文](../RELEASE_1_1_3.md)

## 俄罗斯语

安全和全屏修正macOS.

- ** SQLite/SQLCipher:** RUSTSEC-2026-0459已消除的原因
  (CVE-2026-119375) 如果数据库和WAL页面的大小有出入
  未读的剩余页面现已重置. 正式记录
  SQLite 移植到两个内置引擎; 定期依赖性更新
  这解决不了SQLCipher的问题.
- ** macOS:** 土生土长的面板不再占用申请之上的额外带.
  动向全屏时. 当她离开时,她以前的州会回归.
  处理被应用到常规全屏窗口并保存
  全屏 RDP 后恢复窗口 。
- ** 最小终端在macOS:**按钮SFTP和其他动作
  放置在常见的上部带中,并带有本地缩进,用于系统按钮.
  滚动和拉伸左侧的标签面板不再改变动作
  在窗口按钮下。 当更改标签的位置时,会话和调色板会被保存.
- ** 检查:** WAL 读取回归检查页大小和边框
  缓冲;初始函数起到负控的作用. 审计检查
  修正后的C码的Hashes,头条,Rust包装和构建脚本.
  正在检查加密、 密钥更改、 数据库重新打开和搜索 。

本地数据库和同步格式不变. 更新服务器
此发布不需要同步.

包件:Windows,macOS,LinuxDEB/RPM,Android,个人APK/AABs for RuStore
和 iOS Mac 的模拟器. 模拟器没有安装在iPhone上.
