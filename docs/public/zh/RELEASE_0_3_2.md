# ConsoleCrypt 0.3.2 (韩语).

参考文档译文 · [俄文原文](../RELEASE_0_3_2.md)

通过GitHub行动建立新领域。

- 站点与指南: [consolecrypt.dev](https://consolecrypt.dev).
- 客户端、服务器和文档来源分别存放GitHub .
- 新签名更新种子:`updates.consolecrypt.dev`.
- 公共服务器地址示例:`https://sync.consolecrypt.dev`
- 保存现有配置文件、寄存器、密钥和同步地址。
  要更新,您不需要删除数据,从您的账户中登录, 或重新创建您的配置文件 。
- macOS,Windows,LinuxDEB/RPM,AndroidARM64和iOS模拟器组装
  在新的GitHub上,行动跑者人数不断增加。

所有主要功能都有:SSH - 终端,RDP带有全屏模式,
在计算机上交换 RDP 中的文本和选定的文件夹, SFTP, 片段, 本地
加密存储,同步和共享访问. SSH/复兴党即将到来
直接到你的服务器上 源代码为AGPL-3.0-只.

名人限制:在 RDP 会议期间更改共享文件夹或其权利
它切断了连接。 更改和连接前保存远程工作
如果有必要,请再次发言。 Android – 预览iOS ZIP只用于
模拟器在Mac上,不安装在物理的iPhone上.
