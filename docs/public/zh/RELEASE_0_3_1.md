# ConsoleCrypt 0.3.1 (韩语).

参考文档译文 · [俄文原文](../RELEASE_0_3_1.md)

综艺编辑.

- 顶部面板、标题和页面内容之间的缩进增加。 当列表处于边缘时,第一行和最后一行不再被滚动效应所掩盖.
- 常见的+按钮打开了保存SSH和RDP主机的列表. 在列表中,您可以通过名称或地址找到连接并添加一个新的主机.
- 在远程桌面部分,右上方的备份按钮被移除. 中央的按钮和标签上的“ +”建议选择保存的 RDP主机 。

## 已知RDP限制

在 RDP会话中更改重定向文件夹或其权利,在某些情况下可能会终止连接. 在更改前,保存远程计算机的工作;必要时,再次连接. 0.3.0版本的这一限制仍然有效。
