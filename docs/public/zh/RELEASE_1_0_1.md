# ConsoleCrypt 1.0.1

参考文档译文 · [俄文原文](../RELEASE_1_0_1.md)

## 俄罗斯语

在此版中,我们加强应用程序的保护,并对密码做笔记更加方便.

- ** Passwords:**开卡中的注解以纯文本显示.
  密码仍然隐藏,数据库KDBX保留加密.
- ** SFTP:** 下载内容首先写入一个单独的文件,然后解剖
  被移至其处. 路由检查防止退出选中的文件夹
  通过simlinks和目录互换;中断下载不会破坏旧文件.
- ** SSH:** 更新的rush和Pageant集成;另加RSA签名
  他们使用盲点 系统随机。 对于新钥匙,我们建议
  Ed25519;上游RSA限制仍在Security.md中描述.
- ** Linux和附属物:** 不安全的GLib 惯性补丁已经移动,
  本土的依赖性已经更新,并替换了几个不支持的组件.
- ** 验证:** 扩大的货运图验证,包括Flustter插件,
  为文件竞速,RSA,GLib和D-Bus兼容性添加回归.

服务器 0.2.5在取消请求时分别修正 Argon2 限制保留
它限制了OIDC的流体反应. 检查使用PostgreSQL的服务器测试
隔离存储 拒绝他人恢复数据.

安全工作继续进行:修复和自动检查
减少风险,但不能取代对未解锁设备的保护。

套件:Windows,macOS,LinuxDEB/RPM,Android和iOSMac的模拟器.
模拟器没有安装在iPhone上.
