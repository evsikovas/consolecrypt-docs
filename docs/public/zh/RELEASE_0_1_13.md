# ConsoleCrypt0.1.13 发证检查

参考文档译文 · [俄文原文](../RELEASE_0_1_13.md)

日期:2026年9月30日 来源-标记`v0.1.13`,承诺`4dd26f2`.
实际使用的Rust桥; `CC_MOCK=false` .

| 平台 | 包裹。 | 原产地版本 |
|---|---|---|
| Windows 10/11 x64 | EXE和便携式ZIP | 0.1.13+1221 |
| macOS 苹果硅和英特尔 | 通用DMG( 通用DMG) | 0.1.13+1222 |
| Android 11+ ARM64 | APK 地图 | 0.1.13+27 |

当 Windows 处理 Enter 时固定回归,但非常规字符 。
现在硬件键盘事件转移当前布局 Unicode; Flutter
标记已处理的事件,以使OS文本输入不重复字符.
IME-组合继续使用本土文本输入. 回归测试
更正前的失败经过: `ф`, `Я`, `ё`, 空间,
通常的拉丁语,密钥保留和Enter. 上一个焦点检查, 隐藏
选项卡、 IME 和 Ctrl+C 被保存。 这是对小蝶事件的测试,不是证据.
物理键盘在所有Windows计算机上工作.

添加的"更新"部分: 启动时自动检查,其断开,手动
检查和下载/启动安装器 。 签署元数据Ed25519,HTTPS
载荷仅限于可信任的地址,安装前会检查SHA-256.
检查了错误的签名,密钥替换,过期日期,回扣禁令,
裁剪/ 太大的文件、不正确的文摘、 重定向到他人的
域名,保存开关,错误后重复,Android权限
由用户进行往返和取消安装。

GitLab管道155 / jobs1221,1222 成功组装Windows和macOS.
对两个跑者进行了静态分析和所有406个蝶式测试。
ZIP通过了CRC; Windows版本资源包含0.11.3+1221.
DMG通过诚信检查`codesign --verify --deep --strict`
捆绑版本1222和x86_64/arm64架构;内部有应用链接.
APK包含Name0.1.1.13/versionCode27版本,已经通过签名验证.
`zipalign -P 16`和所有三个本土图书馆的ELF对齐.
APK证书与之前的版本相同,因此上面的安装是相容的.

无论API和网站, 已部署已关闭的更新发布器
大众吉特. 他每5分钟读一次,检查每个人的包裹.
平台和签名的饲料。 一个达特客户已经核实了真正的节点签名.
签名密钥仅可供出版商使用;web Pod不接收. 数据
存储和账户不参与检查更新。

限制:安装仍需对有问题的Windows10进行验收
计算机与物理Android. Windows Inno安装和关闭
客户端; Android 需要系统验证; macOS 打开 DMG
由用户替换应用程序。 此运行中的安装器没有启动 。
替换现有的应用程序。 一揽子方案仍然是初步的:
Windows没有认证码, macOS没有苹果公证, APK
开发证书.
