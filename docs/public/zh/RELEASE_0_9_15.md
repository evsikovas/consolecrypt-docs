# ConsoleCrypt 0.9.15 (中文(简体) ).

参考文档译文 · [俄文原文](../RELEASE_0_9_15.md)

## 俄罗斯语

为macOS,Windows,Linux和Android发行. 同步服务器不改变:它适合
任何支持的服务器(0.2.1及以后)。

** 已取消:会议不再暂停。**

- 一旦存储器自动锁定(或手动锁定),则全部打开.
  培训班继续工作:SSH 终点站和当地终端站、区域发展方案会议、
  SSH 隧道和会场Kubernetes设有子码头和端口滴滴. 过不久.
  解锁被关闭了
- 当存储器被锁定时,没有打开新的连接,RDP标签在背面.
  暂停;解锁后,一切从同一个地方继续.
- 如果锁定时与集群的连接设置Kubernetes 已更改, 则将会是
  会话再次关闭和打开,如同在改变设置时一样。
- 当配置文件更改和退出时,会话仍然关闭. SFTP,Docker和连接
  数据库在被封锁时会像以前一样被关闭.

**新:物理安全密钥(YubiKey,FIDO2) - 预览版。**

- 存储器可以用USB安全密钥打开— YubiKey 或另一个带有安全密钥的FIDO2密钥.
  扩展名`hmac-secret`及其PIN代码. 列入** 安排_储存_
  物理安全密钥**,锁屏上出现按钮
  "解开安全钥匙"
- 操作于 Windows 10/11 (PIN and touch asking window Windows), 管理员权限
  不需要)和macOS(PIN询问应用程序,然后显示"Touch the key").
  Linux和移动平台尚未支持.
- 此函数是可选的, 并用于此设备上的存储: 密钥
  将存储密钥密封到本地信封中,它不同步,
  它去备份和服务器。 密码短语和恢复密钥继续
  工作时。 详细情况:[Ключ безопасности](SECURITY_KEY.md).
