# 缓冲交换/ 剪贴板

参考文档译文 · [俄文原文](../CLIPBOARD.md)

## 俄罗斯语

ConsoleCrypt从三个方面复制数据.

- ** 保密** - 密码、密钥、披露值Kubernetes
  环境Docker,敏感数据库单元格,设置单词
  从 RDP会话缓冲恢复文本 。 它们不会落入缓冲器的历史之中
  其他设备被缓冲器管理者贴上秘密标签并删除
  缓冲过定时.
- ** 个人文本** -在终端和日志中的分配,请求的结果。 没有。
  输入缓冲器和其他设备的历史,但不删除:
  航站楼的工程不得干扰. 如果分泌物看起来像一个秘密
  `password=…`,符号,私钥,被抄写为秘密.
- ** 普通文本** - 路径,标识符,公钥,命令.

删除期设于“Settings → Security → Clear the 剪贴板”中 :
30秒到1天,默认30秒. 团队政治只能是
缩短刑期。 Term 正在经历应用程序重新启动 。 缓冲,只有
如果这仍然是我们的秘密你后来在另一个应用中复制的东西
不洗不净. 如果设备上没有安全缓冲器, 应用程序
上面写着“不可能安全地复制,”它没有复制任何东西。

| 平台 | 保证什么 |
|---|---|
| Windows 10/11 (中文(简体) ). | 秘密不输入缓冲日志(Win+V)和云缓冲;缓冲显示器遵守协议Windows跳过. 在关闭应用程序窗口时及时删除 。 |
| macOS 12+ (中文(简体) ). | 该秘密不会通过通用剪贴板进入iPhone/iPad,该剪贴板标记为隐藏和临时的缓冲管理器. 在离开申请时及时删除。 |
| Linux(GTK、X11和Wayland) | 密钥只存在于剪贴板中, 而不是用于插入中键的配置中 。 缓冲管理器被标记为“ 机密”( KDE Klipper 将它考虑在内) 。 离开申请时,秘密消失,不会传递给缓冲器管理者. |
| iOS (中文(简体) ). | 只有在这个设备上(没有Handoff),即使应用程序被卸载,系统也会及时去除这个秘密. |
| Android 11+ (中文(简体) ). | 该秘密被标记为敏感:在系统复制通知和键盘提示中不可见. 被闹钟系统移除,即使应用程序被折叠或卸下;在节电模式下——延迟时间最长为~10分钟. |

** Android背景.** Android 防止折叠的应用程序读取缓冲
所以我们不能证实它仍然是我们的秘密。 设置
清除背景中的缓冲器,即使你无法证实我们的秘密。
(默认包含) 清除缓冲器而不检查 -它可以消失
在等待期间复制到另一个应用程序的文本。 若为:
关闭它, 秘密留在缓冲,直到你返回ConsoleCrypt.
然后,我们的秘密被删除,但别人的文本不是。 重新启动电话后
下次应用程序打开时, 清理工作将完成 。

限制:删除前已经读取缓冲器的应用程序可以
保密;不支持笔记的缓冲管理器可能
写下来
