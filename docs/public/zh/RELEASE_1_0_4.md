# ConsoleCrypt 1.0.4 (中文(简体) ).

参考文档译文 · [俄文原文](../RELEASE_1_0_4.md)

## 俄罗斯语

密码管理器现在可以重命名和删除组KDBX .

- 在计算机上,打开文件夹中的菜单QQ,或者用鼠标右键点击.
- 在电话中,通过组按钮选择一个文件夹,然后打开旁边的QQ.
- ** 重命名** 更改选中文件夹的名称, 保存其记录和嵌入组 。
- **删除** 需要确认,并将包含所有内容的文件夹转移至回收本KDBX.
  篮子里的根组和文件夹都受到保护,不受这些动作的影响.
- 如果系统篮子位于正则文件夹内,则禁止删除其母项.
  改名仍可考. 这可以防止窝内内容的丢失.
- 两个操作自动保存到本地文件或通过WebDAV.
  如果文件从外部发生了变化,则维持先前的防止覆写的保护.

更正载于Windows、macOS、Linux、DEB/RPM、Android和iOS模拟器。
iOS模拟器的设计是在Mac上运行,而不是物理的iPhone.
同步协议和服务器计划不改变;您不需要更新此修补的同步服务器 。

在CI中取消了赛事准备状态测试Linux——分组赛. 这个检查通过。
在启动所有平台的本地构建之前; 错误现在显示一个特定的
阶段,不公布该组的秘密和原始数据。
