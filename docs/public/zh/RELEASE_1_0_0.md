# ConsoleCrypt 1.0.0 (法语).

参考文档译文 · [俄文原文](../RELEASE_1_0_0.md)

## 俄罗斯语

密码管理器KDBX建在工作空间ConsoleCrypt:本地数据库.
WebDAV,生成器和通过命令调色板搜索. 为Windows,macOS,
Linux DEB/RPM, Android和 iOS Mac上的模拟器. 模拟器不是iPhone安装器.

- ** Passwords:** 创建和打开KDBX 3/4 带有主密码和密钥文件,
  文件夹、卡片、额外字段、编辑、传输和篮子。
  更改会自动保存; PCM在计算机和记录菜单上
  手机允许您打开,移动或删除确认记录.
- ** WebDAV:** 完整 HTTPS - 路径到 KDBX,加密的安全连接
  同步ConsoleCrypt. 连接密码被单独保密 。
  文件版本控制可以防止覆盖其他人的更改;打开可以取消.
- ** 发电机:** 8-128个字符,选集,排除类似字符,
  嵌入式评估,插入编辑器和一般保护剪贴板.
- ** 标牌:**`Ctrl+K`/`⌘K`_`пароли:`_寻牌_选字段.
  抄袭. 搜索是本地的;秘密不由AI传送,也不自动插入终端.
- ** 快速开启KDBX:** 系统生物鉴别系统下单独的本地信封
  或 PIN 设备;在Windows/macOS上,还配有PRF的FIDO2。 Android 用途
  系统键盘和确认请求。 主密码仍然可用。
- ** Phone:** 适应性布局,触摸菜单,可持续存储
  已导入KDBX,并通过系统对话框输出. 本地文件在
  电话 - 应用程序中的复制件; WebDAV 直接在服务器上编辑。
- **隧道:**通过时检查"拯救隧道"Docker/Kubernetes.
  从"隧道"区段重新启动并停止. 这些参数为本地到
  现有SSH隧道继续同步贯通.
- ** 本地AI用于Linux:** 安装经核实的CPU运行时间和相同的GGUF型号
  型号选择,RAM建议,取消/恢复启动并运行而不使用云.
  DEB/RPM包包括OpenMP/OpenSSL的依赖性;权重由用户选择单独加载.
- ** 工作空间:**在连接编辑器中查看密码,
  单独登录/密码/域名 RDP, 共享访问中的命令, 复制
  主机地址/用户,改进的输入字段和终端标签.
  于Windows有`Ctrl+V`,`Ctrl+Shift+V`和`Shift+Insert`.

服务器和网站版本独立于客户端. 用于KDBX/WebDAV未加
新的HTTP端点或服务器迁移:它存储以前的加密对象.
在设置WebDAV 之前, 将所有设备升级到 1. 0 : 旧客户端可以
更改一般设置时不要保存新字段 。
