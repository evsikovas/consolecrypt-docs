# ConsoleCrypt0.4.1 (中文(简体) ).

参考文档译文 · [俄文原文](../RELEASE_0_4_1.md)

## 俄罗斯语

- Android:用于RDP的Touchpad模式. 指向光标相对于当前移动
  位置; 触摸按左键,两个手指滚动, 触摸两个
  用手指按下右键. 可供拖放和分离保留
  屏幕上的键盘。 紧凑面板可以节省手机的工作区.
- Windows/macOS:从设置安装本地AI. Quen2.5-编码器 1.5B Q4_K_M
  通过SHA-256验证下载;lama.cpp包含在macOS包中,并单独列出
  它被设定为Windows. 默认模式
  仅在此设备上选中, 开始于请求和卸载
  15分钟后无动静. 苹果硅使用Metal,Windows使用CPU.
  本地查询通过现有的上下文过滤器和命令确认.
- 固定自动锁定,以防无活动,并取消AI生成.
- 仅通过`main`的标签来收集客户的释放情况。 Linux使用自制软件
  k3s ARC runderAndroid是具有前一个签名密钥的Mac runder.
- 在干净的macOS跑车上,Fluster预装平台的SDK到
  可可Pods设施. 在发布前检查每个安装器的大小 。

本地AI在macOSARM64/x64和Windowsx64提供. 正在装入模型 - 大约
1.1GB+引擎;安装需要互联网连接,而不是回答.
模型很小,可能是错误的:命令只有在确认后才能执行.
iOS 包件仍然是模拟器的预装.

** 旧装置的最新情况:** 旧地址`updates.consolecrypt.evsikov.net`
今已无现. 如果内置验证使用,则下载安装器.
与[страницы загрузок](https://consolecrypt.dev/download?lang=ru),关闭
ConsoleCrypt并更新现有安装;用macOS取代应用程序
申请. 保存备份和复原工具箱。 仓库,
应用数据和系统密钥链无需删除. 新建筑
从`updates.consolecrypt.dev`接收更新.
