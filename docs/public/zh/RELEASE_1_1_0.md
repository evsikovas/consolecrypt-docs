# ConsoleCrypt 1.1.0 (中文(简体) ).

参考文档译文 · [俄文原文](../RELEASE_1_1_0.md)

## 俄罗斯语

最小化桌面终端,更方便用户的密码管理器和
单独Android - 组装为RuStore.

- ** Windows,macOS和Linux上的微观主义**:终端上方的按钮和
  Ctrl+Shift+M/M 隐藏应用程序栏,离开终端和标签.
  标签可以放在顶部或左边. 公开会议,退出,分部
  终端和Ctrl+K/K调色板被保存. 在电话上,这个模式不会打开.
- **SFTP来自终端**:左上方的按钮和PCM中的动作"Open SFTP"
  by SSH - 相应的服务器的标签打开文件, 保存终端
  届会。 也以最小化模式运作.
- ** Passwords KDBX**:列表仅显示解锁数据库. 小个子.
  锁定按钮打开所储存的剩余数据库;其参数WebDAV和
  控制菜单在解锁前仍然可用.
- 过滤器“所有记录” 和“无文件夹”从真实的组合、 篮子 -从
  活动文件夹 。 等级和数据KDBX保存完好. 场牌是钢牌
  它更为紧凑,包括长值和增加文本尺度。
- 在开通线WebDAV - 碱基中,快速访问设置菜单可以通过
  系统认证和支持这些方法的物理密钥.
  第一个解锁需要密码;维持FIDO2平台限制.
- ** SQL**: 线条垂直和水平滚动条增加
  当指点和拖拽的时候。 保留编辑和固定栏目。
- ** 设置**通过点击块头折叠;输入值
  他们还在那里。 科SFTP更名为"SFTP故障编辑器".
- ** RuStore**:生产上分别署名的APK和AAB,用于Android11+ARM64.
  没有要求_INSTALL_PACKGES或内置APK安装.
  更新通过RuStore. 普通APK仍然是一个独立的信道.
  与以前安装的版本兼容.

对于RuStore,使用永久应用程序和下载密钥. 新设
生产密钥与以前的Android预览/调试密钥不同 :
在这种装置之间的过渡过程中,保存本地数据的备份副本。
公布GitHub的档案并不意味着节制RuStore.

可用Windowsx64,通用macOSDMG,LinuxDEB/RPM,AndroidAPK,
RuStoreAPK/AAB和iOSMac上的模拟器. 模拟器存档没有安装在iPhone上.
同步服务器和加密数据格式不变;更新
此发布不需要服务器 。 与苹果"Passwords"的集成不添加.
