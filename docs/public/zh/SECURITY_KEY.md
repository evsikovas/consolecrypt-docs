# 安全密钥( YubiKey, FIDO2)

参考文档译文 · [俄文原文](../SECURITY_KEY.md)

## 俄罗斯语

存储器可以用物理USB安全密钥打开— YubiKey 或
另一个带有扩展`hmac-secret`及其PIN代码的FIDO2密钥. 函数
可选并单独包含每个存储单元
装置。 密码短语和恢复密钥继续工作:如果密钥
丢失或它的 PIN 被屏蔽,用密码短语打开存储 。

** 工作地点(初步版本):**Windows10/11(通过系统版本)
WebAuthn, PIN 请求窗口Windows 和 macOS
宾州网. Linux和移动平台尚未支持.

### 如何打开它

1. 用密码句解锁金库 。
2. ** 设置 → 存储 → 实体安全密钥** – 启用.
3. 插入密钥, 输入其 FIDO2 PIN 代码, 并两次打开密钥:首先
   触摸器记录了钥匙,第二个收到信封的秘密.

密钥必须有一个FIDO2 PIN. 如果不是,Windows将提议在下列地点创建PIN:
第一次注册;在macOS,请向尤比科认证员询问. 经八部.
FIDO在密钥上被屏蔽 -您只能删除锁
重置 FIDO,同时删除密钥上的所有注册 。

### 如何解锁

在锁屏上,按**解锁与安全密钥**,输入PIN.

### 如何是通义.

* 当打开时,密钥会创建一个账户`consolecrypt.dev`.
  它仅作为ConsoleCrypt中的识别器存在. 意外发生
  盐键以32字节的HMAC响应,与WebAuthn PRF值相同.
  此答案将存储密钥密封到本地信封中 。
* 信封和盐仅在此设备上的配置文件密钥文件中:它们不是
  它们是同步的,不要进入备份和服务器.
* 没有密钥本身及其PIN的盐和标识符都不会打开存储器.
  另一把钥匙,即使是同一个制造商,也会有不同的答案.
* 关闭可以删除信封;密钥遗存上的账户(可以删除).
