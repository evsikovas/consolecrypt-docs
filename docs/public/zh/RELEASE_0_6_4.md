# ConsoleCrypt 0.6.4 (中文(简体) ).

## 俄罗斯语

发布时间为macOS、Windows、Linux和Android。 装配和检查iOS被推迟。

** Kubernetes在计算机上重新设计。**在左边,带有星系的导航器和
可削减的资源类别(负荷、网络、配置、储存、
访问,集群, GitOps, API 组和最爱的用户资源.
集群的第一个屏幕是一个活视图:节点,运行的吊舱,命名空间,
问题,CPU加载和内存的图和状态吊舱. 如果在分组中
无度量服务器,基本版本可以从审查中安装(针对本地)
集群有一个模式`--kubelet-insecure-tls`. 物体卡开.
表格上方的 AI 分组助手 -在右面板、 日志底面板和
终端不压缩表.

- 按右键点击分组菜单:重命名、属性、标记为
  测试或产品,标签颜色,通过同步服务器共享
  导出 kubeconfig 。
- 产品集群中的录制窗口由存储密码确认.
- 编辑YAML本身检查服务器上的更改. 创建 pods (已创建)
  控制器现在被编辑;如果拒绝, 则显示哪个控制器
  拥有字段或服务器拒绝的字段。
- 表格和审查显示吊舱的现状(运行、完成、
  CrashLoopBackOff;没有状态的对象(Service, CfigMap)没有列.
- GitOps:审查不再下降, 资源流由左向右构建
  与豪华循环。
- 港口溢出物是右面板的一个单独工具;事件的历史.
  带有下拉文本的卡片。
- AIKubernetes与本地内置模式合作并减少上下文
  为小模型。

** 任期和关系。**

- 终端字体是从安装的单线字体中选择的.
- 菜单标签:重命名,重复,关闭其他标签和右标签.
- 在侧菜单中突出显示带有新输出的背景标签 -
  这些标签的单独计数器。
- 标签签名:从列表中的名称,地址或计算机名称,或无.
- 从`~/.ssh/config` 导入主机( 插件、主机、 代理汉字和密钥)
  从身份档案。
- 热密钥在设置中重新分配, 并警告
  冲突与重定标准。
