# ConsoleCrypt 0.3.2

Referencia traducida · [Original en ruso](../RELEASE_0_3_2.md)

Nuevo dominio y construye a través de GitHub Acciones.

- Sitio y guía: [consolecrypt.dev](https://consolecrypt.dev) .
- Cliente, servidor y fuente de documentación en repositorios separados GitHub .
- Nuevo alimento de actualización firmado: `updates.consolecrypt.dev` .
- Ejemplo de una dirección del servidor público: `https://sync.consolecrypt.dev`
- Se guardan perfiles existentes, repositorios, claves y direcciones de sincronización.
  Para actualizar, usted no necesita eliminar datos, salir de su cuenta o recrear su perfil.
- macOS , Windows , Linux DEB/RPM, Android ARM64 y iOS Simulador montado
  En el nuevo GitHub Actuaciones corredores con números de construcción crecientes.

Todas las características principales están disponibles: SSH - terminales, RDP con modo de pantalla completa,
intercambio de texto y carpeta seleccionada en RDP en computadoras, SFTP , snippets, local
almacenamiento cifrado, sincronización y acceso compartido. SSH / RDP que viene
Directamente a sus servidores. El código fuente es AGPL-3.0 solo.

Famosa limitación: cambiar la carpeta compartida o sus derechos durante una sesión de RDP
Corta la conexión. Guardar el trabajo remoto antes de cambiar y conectar
de nuevo si es necesario. Android – vista previa iOS ZIP está destinado sólo para
Simulator está en un Mac y no se instala en un iPhone físico.
