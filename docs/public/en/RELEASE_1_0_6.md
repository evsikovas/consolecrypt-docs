# ConsoleCrypt 1.0.6

Translated reference · [Russian source](../RELEASE_1_0_6.md)

## Russian

The password manager basket KDBX now has a shopping cart icon and understandable actions.

- When selecting a basket or folder inside it, the button ** Clear the basket** is available.
  This action is also in the **.**/PCM menu of the cart itself.
- Upon confirmation, all groups, nested groups and
  entries** baskets. Existing data outside the basket is stored.
- For a separate remote group or menu entry, **Delete Forever** is available.
  It's also confirmed. Deleting a group includes its nested folders and records.
- The system folder of the basket remains empty. An ordinary folder called Trash
  Defined as a regular folder: actions are linked to the basket ID KDBX.
- Changes are immediately stored locally or through WebDAV. Search within the selected
  Recycle bins find deleted entries; the general search and palette continue to exclude them.

The fix is available on Windows, macOS, Linux DEB/RPM, Android and iOS Simulator.
The synchronization protocol and the server do not change.

Also, the assembly Windows of the installer with large numbers of CI-assemblies was corrected.
The full version of the application and check for updates are saved.
