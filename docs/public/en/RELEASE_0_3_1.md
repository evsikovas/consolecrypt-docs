# ConsoleCrypt 0.3.1

Translated reference · [Russian source](../RELEASE_0_3_1.md)

Cosmetic edits.

- Increased indentations between the top panel, headings and page content. The first and last lines are no longer obscured by the scrolling effect when the list is at the edge.
- The common + button opens a list of saved SSH and RDP hosts. In the list, you can find a connection by name or address and add a new host.
- In the Remote Desktop section, the backup button on the top right is removed. The button in the center and the “+” at the tabs suggest selecting the saved RDP host.

## Known RDP Limitation

Changing the redirected folder or its rights during an RDP session may, in some cases, terminate the connection. Before changing, save the work on a remote computer; if necessary, connect again. This limitation of version 0.3.0 is still in place.
