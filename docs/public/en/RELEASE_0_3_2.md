# ConsoleCrypt 0.3.2

Translated reference · [Russian source](../RELEASE_0_3_2.md)

New domain and builds through GitHub Actions.

- Site and Guide: [consolecrypt.dev](https://consolecrypt.dev).
- Client, server, and documentation source in separate repositories GitHub.
- New signed update feed: `updates.consolecrypt.dev`.
- Example of a public server address: `https://sync.consolecrypt.dev`
- Existing profiles, repositories, keys and synchronization addresses are saved.
  To update, you do not need to delete data, log out of your account or recreate your profile.
- macOS, Windows, Linux DEB/RPM, Android ARM64 and iOS Simulator assembled
  On the new GitHub Actions runners with increasing build numbers.

All the main features are available: SSH - terminals, RDP with full-screen mode,
exchange of text and selected folder in RDP on computers, SFTP, snippets, local
encrypted storage, synchronization and shared access. SSH /RDP coming
Directly to your servers. The source code is AGPL-3.0-only.

Famous limitation: Changing the shared folder or its rights during an RDP session
It cuts off the connection. Save remote work before changing and connect
again if necessary. Android – preview iOS ZIP is intended only for
Simulator is on a Mac and does not install on a physical iPhone.
