# ConsoleCrypt 0.5.6

Translated reference · [Russian source](../RELEASE_0_5_6.md)

## Russian

Fixed the Recovery Kit display on the phone. Number of columns with words
It depends on the width of the screen and the size of the text. On a narrow screen, a QR code
It is below words; numbers and words do not overlap. Maintained
enlarged system font.

The release includes a full-screen mobile RDP with a relative touchpad,
on-screen keyboard and gesture settings, import SSH hosts from `known_hosts`
local terminal in the command palette and correction of indentation from the system buttons
macOS. More info: [изменения 0.5.5](RELEASE_0_5_5.md).

Existing storages, keys, and downloaded local AI models are saved.
